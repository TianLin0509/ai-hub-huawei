# 界面语言（英文版）开发约定

2026-11-20 起。所有用户默认中文；只有在「设置 → 界面语言 / Language」里选了 English 才显示英文。不读系统语言。

## 工作原理

- `core/i18n/index.js`：词典与翻译函数，主进程和界面进程共用。词典按「中文原文 → 英文」写在 `core/i18n/locales/en/*.json`，带 `{0}` `{1}` 的是句式（例如 `"已恢复 {0}/{1} 个会话": "Restored {0}/{1} sessions"`）。
- `renderer/i18n-dom.js`：选了 English 时，把界面里的文字和提示类属性（title、placeholder、aria-label、data-hub-tip 等）按词典换成英文；界面脚本之后写进来的中文由 MutationObserver 在绘制前换掉。中文模式下这一层不启用，界面与以前逐字相同。
- `main/i18n-main.js`：主进程的系统对话框、菜单、托盘提示、系统通知统一按词典翻译，调用点不用改。
- 不翻的区域：会话正文、终端、输入框、代码、公式、预览（见 `SKIP_SELECTOR`）；其他要排除的元素加 `data-i18n-skip`。

## 写新界面文字时

1. 照常写中文。
2. 在 `core/i18n/locales/en/<分组>.json` 加英文译文。带变量的句子写成句式：`` `待送达 ${n} 条` `` 对应 `"待送达 {0} 条": "{0} pending"`。
3. 用 `node scripts/i18n-extract.js --scope <分组> --missing --unique` 查还缺哪些；文件属于第一期范围的，放进 `core/i18n/scope.json` 对应分组。
4. 给 AI 的提示词、按中文原文匹配的正则、日志不翻：在该行加注释 `i18n-ignore`，或把原文登记到 `core/i18n/ignore.json` 并写明原因。

## 容易出错的写法

- 把一句话拆成几个元素或用 `+` 拼接（`'共 ' + n + ' 条'`），运行时界面上的文字和词典对不上。优先改成一个模板串整句；改不了的，按界面上实际显示的整段加句式。
- 程序读界面文字再和中文比较（`el.textContent === '正在下载…'`）：英文模式下读到的是英文，判断会失效。改成比较状态变量或 data 属性。
- 英文更长：按钮、页签、侧栏在 1440×900 下截图检查，不溢出、不异常换行；放不下的用省略号加悬停提示。

## 验证

- 单测：`tests/unit-i18n.test.js`（底座）、`tests/unit-i18n-coverage.test.js`（第一期范围漏翻数只许减不许增；英文词典无中文、占位对应、同一原文译法一致）。
- 截图：`node tests/capture-i18n-cdp.js --out <目录>` 在隔离数据目录启动 Hub，按 1440×900 截英文界面，并在 `residual.json` 列出屏幕上残留的中文。加 `--lang zh-CN` 截中文对照。
