# 号池内网共享

主机保存公司账号登录态并运行号池。同事连接模型网关，在自己的电脑上运行 Claude Code、Codex 或 DSH；工具执行和项目文件仍在同事电脑上。主机只转发模型请求、提供经过筛选的只读额度快照。

## 主机

设置 → 号池内网共享 → 本机提供共享。选择公司内网网卡、端口，开启共享；按人生成专属口令，并设置同时请求数和每分钟请求数。页面显示的地址和口令交给对应同事，口令只显示一次。撤销口令立即取消该同事的在途请求。

共享默认随 Hub 起停。保持主机开机、联网、Hub 运行。当前没有默认开机常驻、防睡眠或无密码登录续期。已有登录缓存过期时，主机提示账号主人重新登录。

## 同事

设置 → 号池内网共享 → 连接共享主机，填写地址和专属口令。验证通过后，新建 Claude Code、Codex、DSH 会话使用共享模型；连接前的各工具配置会保留。断开时恢复原配置，连接之后手动改为自有 API 的工具配置保留。

右侧「共享号池额度」和启动中心展示主机的模型、逐号余量和读数时间。所有同事共同消耗账号额度；刷新只同步主机已有读数。主机离线或撤销口令后，保留旧读数并注明原因，不静默改用本机账号。第一次上线应从另一台公司电脑发一条小请求，验证办公网入站连接。

## 自动恢复与提示（5.5.17）

- 主机：共享启动失败（模型服务没就绪、端口被占、网卡暂时不可用）时弹常驻提示，之后每 30 秒自动重试，恢复后再提示一次；电脑休眠唤醒后自动重新检查。
- 主机内网地址变化（DHCP 换 IP、有线/无线切换）时，共享自动换到当前内网网卡，并提示把新地址发给同事；长期使用建议给主机固定 IP。
- 同事：主机掉线时每 30 秒自动重连，恢复后提示；口令被撤销单独显示「口令已撤销」，停止自动重连，可在设置里用新口令重新连接。离线期间各号保留上次状态和读数，但不计入可用数。
- 主机生成口令时同时给出一行「连接信息」（地址 + 口令），同事整行粘贴即可连接。撤销口令需二次确认。
- 账号页顶部显示共享卡片：主机看到同事列表、本次请求数、最近使用时间；同事看到共享号逐号今日额度、自己的上限与用量。
- 共享配置文件损坏时改名为 `settings.json.corrupt-<时间>` 保留，共享回到关闭状态，不影响主机自己的公司模型会话。
- 上游 5 分钟没有任何数据时主动结束该请求并释放同事的并发名额；请求上传超时放宽到 2 分钟。

## 运行边界

- 独立网关默认端口 18766，只绑定指定内网 IPv4 网卡，支持 RFC1918 与 RFC6598 地址段。原有本机反代继续只绑定 127.0.0.1。
- 共享口令为 192 bit 随机值，主机只保存 SHA256；原账号凭据不发给同事。客户端仅保存自己的共享口令。
- 共享端口只开放三种模型协议、模型列表、只读额度快照，不开放 Hub、IPC、文件、终端、代理管理接口。
- 不记录提示词、回答或原始凭据；管理员看到本次 Hub 运行期间的按人请求统计。
- 每位同事与每个会话有独立调度标识，复用原号池的粘号、模型权限过滤、429 换号和冷却。
- 支持 Claude Code 的 `?beta=true` 元数据。SSE（流式事件）直到结束才释放并发；DSH 收到 DONE 后主动断流算正常完成，HTTP200 中的流式错误计为失败。

## 开发验证

专项：`node --test tests/unit-lan-pool.test.js`。

界面：`node tests/e2e-lan-pool-cdp.js`。设 `LAN_E2E_REAL_CLI=1` 可额外跑真实 Claude/Codex 读文件闭环；上游仍为模拟模型，不消耗真实 AI 额度。所有 Hub、CLI 配置和测试文件均隔离。报告明确区分本机双进程、公司单机、公司两台电脑三种证据。

按项目规则运行全量 `npm test`、公开版生成审计和改动文件语法检查后，再进入合入或发布流程。
