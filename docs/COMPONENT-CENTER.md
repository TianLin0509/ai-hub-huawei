# 功能体检与组件中心

设置菜单 → **功能体检与组件中心**。成员版和公开版共用这项功能。

- **功能体检**按 CodeAgent 会话、各 CLI 的公司模型接入、消息助理、PPT 联动列出依赖。点击依赖进入对应组件或设置；“组件已就绪”不等于账号已登录或真实模型请求成功。
- **组件中心**直接调用既有的 Claude Code、Codex、DSH 安装器，显示进度、取消与重试。CodeAgent、WeLink 等内部工具继续使用现有内部安装入口或助理页安装说明，不由公共组件镜像分发。
- **PPT Doctor**从现有镜像下载完整包，核对 SHA256 和大小，在 Hub 数据目录的独立目录解压，再核对联动标记及可执行文件哈希，全部成功才登记到 PPT 设置。安装过程不启动 GUI、不覆盖原安装；失败或取消保留原设置。镜像可能保留旧版完整基线，页面明确显示实际安装版本，后续更新由 PPT Doctor 提供。
- **环境明细**保留原有环境检查、错误说明、重新检测和脱敏结果复制。

安装完成自动复检；从内部下载页返回时复检。检测不自动安装、不刷新模型登录。

## 验证

```powershell
node --test tests/unit-component-center.test.js tests/unit-env-check.test.js tests/unit-company-assistant-ppt-download.test.js
node tests/e2e-component-center-cdp.js <证据目录>
```

界面测试使用真实隔离窗口和鼠标输入，工具状态/下载结果为本地夹具。真实发布包安装另用独立数据目录验证，不等于真实公司模型接入验证。公开版也需要导出后执行这些检查。

PPT 解压脚本必须在打包时放入 `asarUnpack`；安装器解析到实际文件路径后调用。不得省略 ZIP 路径验证、哈希与联动能力检查。
