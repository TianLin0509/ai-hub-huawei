# 在 Hub 中使用 CodeAgent 技能

技能是一份可重复使用的工作说明，通常由 `SKILL.md` 和配套文件组成。例如，一个技能可以规定如何整理报告、分析资料或完成某类开发任务。选择技能后，还需要写清这一次要处理什么、需要什么结果。

本页介绍 CodeAgent 会话的技能选择器。其他 CLI 会话沿用各自的使用方式。

## 选择技能并发送要求

1. 打开一个 CodeAgent 会话，在输入框下方的模型、推理强度控件旁点击「技能」。
2. 搜索已安装技能，名称和说明都可搜索，不区分大小写。列表会显示技能名称、说明；技能提供了参数提示时，也会一并显示。
3. 点击技能，它会以标签放在输入框开头。继续在标签后写本次要求，例如「根据这些资料整理一页总结，列出结论和待确认项」。
4. 按 Enter 发送。Hub 会按 `/<技能名> 本次要求` 提交给 CodeAgent；没有正文时，只提交 `/<技能名>`。

一次只能选择一个技能。再次选择会替换标签，点击标签上的 × 可删除。切换会话后，未发送的标签和正文会随草稿恢复。技能标签只是选择入口，技能的实际执行仍由 CodeAgent 完成。

通过标签成功发送后，技能会进入「最近使用」，最多显示 5 个，最近使用的排在前面。个人账号与各号池账号分别记录；已卸载的技能不再显示。其他已安装技能在「全部技能」中按名称排序。

## 输入 `/` 快速选择

在输入框开头输入 `/`，光标仍在第一个词中时，会弹出同一个技能列表。继续输入可按名称和说明过滤，例如 `/ins`。

- 技能选中后变成标签。没有匹配技能时，会出现「在终端执行 /xxx」；选中后切到该会话的终端，单次提交输入框里的完整命令和参数，并清空卡片输入框。请在终端继续操作。
- 顶部搜索框和底部两个入口固定显示，中间技能列表可滚动。
- 用上下方向键在列表项和底部两个入口之间选择，按 Enter 确认，也可以直接点击。
- 按 Esc 关闭列表。列表关闭后，原有的发送和输入历史快捷键继续可用。
- 中文输入法组字期间不会弹出列表或截走候选词的回车。

## 打开 CodeAgent 内置命令

点击列表底部固定的「CodeAgent 内置命令」。Hub 会切到终端视图，确认 CLI 输入行为空后，只输入一个 `/`，不按回车，由 CodeAgent 自己显示当前版本的命令列表。

如果终端输入行已有草稿、无法确认是否为空，或会话正在回答、等待交互，Hub 不会写入。请先在终端处理当前内容，再打开命令列表。

## 从 AgentCenter 添加

点击技能列表底部固定的「从 AgentCenter 添加」，或在 Hub 输入框发送 `/skills`。

Hub 会先切到这个会话的终端视图，再通过现有发送通道提交 `/skills`。随后请在 CodeAgent 自己的技能菜单中选择 **Add from AgentCenter** 并完成安装。Hub 不代为选择或操作终端菜单，也不直接连接技能市场。

会话正在回答或等待交互时，请先完成当前一轮，再打开技能菜单。安装完成后，可回到卡片视图，重新点击「技能」；Hub 会重新扫描目录。若终端显示的菜单或提示与上述名称不同，请以当前 CodeAgent 版本的实际界面为准。

## 技能装在哪里

Hub 按当前会话使用的 CodeAgent 账号配置目录读取 `skills` 子目录：

- 个人账号通常为 `~/.cac/skills`；如果配置了其他 CodeAgent 配置目录，则以该目录为准。
- 号池会话读取该账号自己的配置目录中的 `skills`，不会把其他账号的目录混进来。
- 支持直接的 `<技能>/SKILL.md`，也支持市场多套一层的 `<市场>/<技能>/SKILL.md`。

技能名称和说明来自 `SKILL.md` 的元数据。缺少名称时使用技能目录名；没有说明或参数提示时，对应内容留空。无法读取的目录会显示错误，缺少有效元数据的技能会给出提示。

## 为什么有时要新开会话

Hub 能扫描到文件，不代表正在运行的 CodeAgent 已加载它。新安装技能是否能立即在当前会话使用，取决于 CodeAgent 本身。

若技能目录的修改时间晚于本会话启动时间，标签和发送提示会说明：「这个技能在本会话启动后才安装，若未生效请新开会话」。这不会阻止发送。目录修改时间只能作为提示依据；若当前会话没有响应技能，请新建或重新打开会话后再试。

## 常见问题

### 选了技能却没有反应

选择技能只会放入标签，不会自动发送。请在标签后写要求并发送，查看是否出现提交失败提示。若技能刚安装，尝试新开会话；若终端仍在菜单中，请先退出菜单、恢复普通输入框。不要反复发送同一条未知状态的请求。

### 列表里没有新技能

再次打开「技能」会重新读取目录。确认安装所用账号与当前会话一致，并确认技能目录中有带有效元数据的 `SKILL.md`。号池会话与个人会话可能读取不同目录；目录读取失败时，请按列表中的具体错误排查。

### `/skills` 为什么切到终端

`/skills` 打开的是 CodeAgent 的交互菜单，不是一轮普通问答。Hub 会把终端显示出来，方便你操作；卡片视图不会为这次菜单操作生成普通问答卡片。完成后切回卡片视图即可。
