# AI HUB-H 使用说明书（公开版）

> 版本 v5.6.73 · 生成于 2026-11-20。本说明书随安装包分发，离线可读；Hub 底栏「问问 Hub」按它回答问题。
> 「界面地图」一节由程序从界面代码自动导出，「常见问题」取自用户群里维护人已确认的标准答复，「最近更新」取自更新日志。
> 写法约定：`设置菜单` = 左侧导航最下方的「设置」按钮点开的菜单；`配置弹窗` = 设置菜单里的「⚙️ 设置」打开的窗口。

## 1. 入门：五分钟上手

1. **前提**：公司电脑上装好 CodeAgent 并已登录（命令行 `codeagent --version` 能显示版本）。没装也能先打开 Hub：首页「连接你的 AI」会显示每个 AI 的安装状态，并给出一键安装、一键登录按钮。
2. **第一次打开**：首页「连接你的 AI」里有「新同事三步上手」——① 检测已装工具（没装就地给「安装」）② 选一个能用的模型（CodeAgent 没登录给「一键登录」，只有部门 key 给「用部门 API key」）③ 发第一句话（点「开始第一个会话」，输入框里已填好一句，按回车即可）；三步做完自动收起，不需要可点「不再显示」。已经用过 Hub 的老用户不会看到它，首页顶部仍是「第一次使用：可以先体检一下」，点「点此体检」检查要用的工具装好没有；也可以随时从 `设置菜单 →「🩺 功能体检与组件中心」` 进入，一键安装 Claude Code、Codex、DSH、PPT Doctor 等组件。
3. **新建会话**：左上角蓝色「＋ 启动」直接用上次的配置开一个会话；点旁边的小箭头（或按 Ctrl+N）打开「启动中心」，选 AI（CodeAgent / Claude Code / Codex / DSH / pi / PowerShell）、模型和工作文件夹。工作文件夹就是 AI 查看材料、写文件的地方，启动中心会记住上次用的文件夹。
4. **聊天**：会话里默认是「卡片」视图，下方输入框回车发送、Shift+回车换行（可在 `配置弹窗 →「回车键」` 改成回车换行、Ctrl+回车发送）。输入框下方的模型名点一下就能换模型，对话记录保留。
5. **看原始终端**：会话顶栏的「后台」按钮切到 CLI 原始终端；它右边的小箭头是「后台显示方式」，可选卡片和终端单独显示或左右并排。
6. **多个 AI 一起干活（推荐负责人组队）**：新开一个 CodeAgent 会话，把任务说清楚，加一句「需要的话组队做」，它会自己当负责人、按需招队友分工、审查后向你汇报，你只跟它说话。只有一个账号也能组队（队友共用你的账号）。想自己挑几个不同的 AI 同场讨论、对比看法，再用首页「新建 AI 群聊」，在群聊输入框里 @ 谁就只发给谁。
7. **可选功能默认关**：助理、帖子、考勤、门户待办、关窗口时最小化到托盘、桌宠这些功能默认关闭，在 `设置菜单 →「🧩 可选功能」` 里自己打开。左侧导航上找不到某个页面时，先去这里看看。
8. **数据在哪**：用户数据在 `%USERPROFILE%\.ai-hub-community`，覆盖安装、升级、换版本都不会动它。

## 2. 界面地图：每个页面和设置在哪

> 本节由程序从界面代码自动导出（左侧导航按钮、设置菜单、配置弹窗字段、可选功能清单），与当前版本一致。

### 2.2 顶栏（窗口最上方一行）

- 左边：产品名、版本号（就是你现在用的版本）、「隐藏功能导航」开关、「切换会话栏 (Ctrl+B)」、当前位置（面包屑）。
- 中间：常用工具三个图标——全屏截图到剪贴板、复制选中内容、粘贴到刚才的输入位置。
- 进入会话后右边会出现：「问一下」（在会话旁边插问一句，不打断它手上的工作）、打开工作文件夹、「⋯ 更多操作」（电脑/手机显示预设、显示参数）、「后台」与「后台显示方式」、「沉浸」阅读、单屏/左右二分屏切换。

### 2.3 底栏（窗口最下方一行）

- 左边：CPU、GPU、内存、硬盘占用，以及账号额度；点硬盘或内存可打开一键释放面板。
- 右边：「❓ 问问 Hub」（本说明书的答疑入口）、网络与代理状态、「⋯」查看全部状态、「一键放行」（公司网络拦截 Hub 的下载或反馈时，点它放行）。

### 2.4 设置菜单（左侧导航最下方「设置」）

- **💤 自动休眠**：自动休眠：后台每 5 分钟巡检，连续 5 小时没有输入输出的会话自动休眠；点这一项立即扫描
- **⚙️ 设置**：打开配置弹窗（见 2.5）
- **⬆️ 检查更新**：手动检查并安装新版本（末位小版本不弹窗，要在这里点）
- **🩺 功能体检与组件中心**：功能体检与组件中心：检查各功能依赖，一键安装 Claude Code、Codex、DSH、PPT Doctor 等
- **💬 一键反馈**：一键反馈：写一句现象，附带脱敏的版本环境和日志尾部发给维护人（见第 6 节）
- **🧩 可选功能**：打开或关闭助理、帖子、考勤、门户待办、托盘、桌宠（见 2.6）
- **⌨️ 快捷键**：全部快捷键
- **🕘 版本与回退**：查看已装版本，必要时回退到旧版本
- **📝 更新日志**：每个版本改了什么

### 2.5 配置弹窗（设置菜单 →「⚙️ 设置」）

- **号池内网共享**（弹窗顶部一行，点「管理共享」）：连接团队主机，或向同事共享本机号池

  - **界面语言 / Language**：选择后立即生效 · Applies immediately
  - **会话原模型不可用时**：会话固定创建或手动选择的模型。自动模式只换同家族可用型号；跨家族须手动确认，暂停状态不会因恢复或重启解除。
- 分组「助理桌宠」（立即生效）
  - **在桌面角落显示桌宠**：Hub 开着时出现；会话答完、提醒都由它告诉你，点卡片直接打开。右键可问助理，或让它安静一小时。
  - **角色**
  - **说话频率**：温和：只说助理的提醒；活泼：再加早上问候、久坐提醒；安静：只亮小圆点。每小时最多开口 3 次。
- 分组「桌面回执」（会话答完、提醒弹在哪 · 立即生效）：左栏的未读标记不受影响；小卡右上角的齿轮也能回到这里。
  - **CodeAgent 自带的完成提醒**
- 分组「工作台服务器状态」（阿里云 / 自建健康端点）
  - **在工作台监控服务器**：主进程按需读取健康端点；未配置时不会自动探测任何公网地址。
  - **显示名称**
  - **健康检查 URL**
  - **指标 URL （可选）**
  - **Checkpoint 恢复目录 （可选）**：指标 JSON 可返回 storage.totalBytes / usedBytes / usagePct；保存后回到工作台刷新即可验证。

  - **字体风格**：默认已从 13px 调到 15px；代码块用等宽字体，字号跟着正文字号和 Ctrl+滚轮一起缩放。公式由本地 KaTeX 离线渲染。

  - **负责人组队自动批准**：默认开：负责人提交招人计划后，账号和模型按号池校验通过即直接建成员，不用再到侧栏点「待批准」。关掉后回到人工批准。

### 2.6 可选功能清单（设置菜单 →「🧩 可选功能」）

- **助理**：整理每日简报、提醒待处理的 WeLink 消息，并回答工作问题。会议和会议室可以单独使用。开销：开着时工作日每 10 分钟后台读一次 WeLink，每分钟检查一次登录
- **帖子**：公司发文（政策讲话、公司文件、公告）和心声、稼先今天的热帖，附 AI 摘要；发文上新会提醒。开销：开着时工作日早上在后台用无头 Edge（借本机 Edge 的登录状态，不弹窗）取一次，之后每小时只重看发文；没登录会每 30 分钟重试
- **考勤**：读自己的打卡记录，统计加班、80 小时红线和年度工时。开销：开着时每天在后台打开一次考勤页（隐藏窗口，取不到时用无头 Edge），当天取到就不再访问
- **门户待办**：读公司门户首页上自己的待办、提的申请和公司文件；新待办、拖了很久的待办和卡住的申请会提醒。开销：开着时每天早上 6 点后在后台用无头 Edge 打开一次门户首页（约 10 秒、不弹窗），当天取到就不再访问；页面上可随时手动刷新
- **会议室**：按你的规则每天放号时自动抢订会议室，结果和快开会了由桌宠或通知卡提醒。开销：开着时每 15 秒看一次抢订结果；打开过会议室页后，后台常驻一个会议室组件进程（约几十到一百多 MB 内存）
- **关窗口时最小化到托盘**：点窗口右上角的关闭只把 Hub 收到右下角托盘，会话照常在后台跑；单击托盘图标打开，右键「退出 AI Hub」才真正退出。开销：几乎没有，只多一个托盘图标
- **再打开 Hub 时提示切过去**：已经开着一个 AI Hub 时再双击图标，先问一句「已在运行，切过去？」；选「再开一个」照样能开两个。开销：没有，只在打开 Hub 时看一眼
- **桌宠**：桌面角落的小猫：会话答完、提醒、会议室结果都由它举卡片告诉你，右键还能问助理。开销：开着时一直有一个置顶的小窗口，每 0.1 秒看一次光标是否碰到它

## 3. 常用操作怎么做

### 3.1 模型与账号

- **换模型**：会话输入框下方点模型名，选另一个即可，对话不丢。新建会话的默认模型在启动中心里选。
- **模型列表里少了模型 / 选不到**：模型列表读的是本机 CodeAgent 账号的权限，各人不同。先 `设置菜单 →「⬆️ 检查更新」` 升到最新版（旧版曾把名字带括号的模型过滤掉），再到左侧「账号」页确认 CodeAgent 已登录、额度正常；仍然少，就点「💬 一键反馈」。
- **报「模型不存在或配置有误」/ 400 Invalid model name**：这个账号没有该模型的权限或模型改了名（换号、号过期后常见）。点输入框下方的模型换一个；选过一次替代后，新会话会直接用替代模型。
- **CodeAgent 账号、号池额度**：左侧「账号」页管理登录状态和号池；底栏和右侧栏显示剩余额度。
- **用部门 API key / 自己的接口**：三个入口任选——① 首页「连接你的 AI」里的「用 API key 开始」，粘贴 key 即可（网关地址已预填，key 用 Windows 账户加密保存）；② 启动中心的模型卡里点「用部门 API key」，就地粘贴；③ `设置菜单 →「⚙️ 设置」→ 顶部「自有 API」→「配置接口」`，Claude Code、Codex、DSH 每个工具可分别选「公司模型」「API 网关」或「自己的接口」。Hub 还会自动检测你在 Claude Code、Codex、VS Code 等工具里配过的网关 key，一键使用。
- **让 Claude Code、Codex、DSH 也用公司模型**：同上 ③ 里选「公司模型」，走 CodeAgent 登录的公司线路，所以 CodeAgent 必须先登录有效。报「首次签名初始化没完成」时：确认 CodeAgent 命令行能正常对话，再在「自有 API」里点「重新启动反代」。

#### 没有 CodeAgent 账号，接部门自有模型（部门自有平台、部门 GLM 等）

先分清手里是哪一种，再按对应的一条做（都在 `设置菜单 →「⚙️ 设置」→ 顶部「自有 API」→「配置接口」`，上方切换 Claude Code / Codex / DSH）：

1. **部门发的 API 网关 key（通常以 sk- 开头，地址是部门统一网关）**：选「API 网关」，粘贴 key →「保存配置」。保存时 Hub 先请求一次模型列表验证（不发对话、不耗额度），通过后 Claude Code、Codex、DSH 都能勾选同时使用。Claude Code 用这条最稳：Hub 在本机把 Claude 的请求转成 OpenAI 格式。
2. **自己的 OpenAI 兼容地址（平台给了「接口地址 + Key + 模型名」）**：选「自有接口」，填接口地址（一般以 /v1 结尾，漏了 Hub 会自动补）、Key，点「测试连接」——通过后在「接口上的模型」下拉里选模型，再「保存配置」。DSH 必须填模型名；保存后新建 DSH 会话，启动中心默认选中「自有接口」卡。
3. **Claude Code 填了 OpenAI 兼容地址**：Claude Code 只认 Anthropic 格式，直接填会报 404 或格式错误。「测试连接」通过后弹窗里会出现「改用 API 网关接入」，再粘贴一次 key 点它即可，地址、Key、模型照用。
4. **同一个工具有多个平台账号**（Claude Code、Codex）：「API 账号」下拉里「＋ 添加 API 账号」可存多组；选中某个账号能直接改名称、地址、模型（Key 留空保留原 Key），点「删除此账号」再点「确认删除」可删掉。已开的会话不受影响。

常见报错与下一步：

| 看到的提示 | 原因 | 下一步 |
|---|---|---|
| key 无效 / 401 | Key 复制不完整或已失效 | 重新复制完整 Key 粘贴，「测试连接」 |
| 连不上接口：10 秒内没有响应 | 电脑不在能访问该平台的网络里（在家没连 VPN、黄区平台在绿区访问等），或地址写错 | 换到能访问的网络；核对地址 |
| 接口上没有这个模型 | 模型名拼错，或平台换了新模型 | 「测试连接」后在「接口上的模型」里重新选 |
| DSH 还没选模型来源 / 还没填模型名 | DSH 没配任何一种来源，或自有接口缺模型名 | 按上面 1 或 2 配好再新建 DSH 会话 |
| DSH 显示「未安装」 | 这台电脑还没有 DSH 终端运行环境 | 启动中心点 DSH 卡片「一键安装」 |
| DSH 会话一直「启动中」，或报「DSH 启动失败——插件 tools …」 | 装的 DSH 比这版 Hub 新，插件配置不配套（11-20 前的 Hub 遇到 npm 最新版 DSH 必现） | 先升级 Hub 到最新版；仍不行点「一键修复 DSH」或「一键反馈」 |

### 3.2 会话、群聊、组队

- **恢复以前的会话**：启动中心里切到「恢复会话」，可以接任意目录的 CodeAgent 历史；侧栏「搜索历史」（Ctrl+Shift+F）全局搜以前的对话。
- **重命名、分组、置顶**：右键会话「重命名会话」；会话整行可拖进侧栏目录分组；侧栏顶部「置顶 / 今天 / 3 天」切换范围。
- **会话卡住、提示「CLI 已退出，请先重启会话」**：点提示里的重启会话；报错卡片上的「问问 Agent」会开一个排查会话，几分钟内给出排查结论。
- **省内存**：闲置会话自动休眠，内存超过 85% 时先休眠早已答完的会话；点一下会话就唤醒，记录都在。`设置菜单 →「💤 自动休眠」` 可立即扫描一次。
- **负责人组队（多 AI 分工干活的推荐用法）**：不用找入口，也不用先建群——新开一个 CodeAgent 会话，说清任务并加一句「需要的话组队做」，这个会话就是负责人：它判断要不要队友、自己招人、分工、审查，最后向你汇报，你只跟它说话。队友由负责人按任务现招，不用你预先建，也不用每次重选；招来的队友显示在侧栏负责人那一行下面，点开就是普通会话。号池里有可用账号时队友优先用号池；号池没号、或者只有你自己一个号时，队友自动用你的个人账号（和负责人共用额度，个人账号上同时最多 3 个队友在干活，多出的排队）；不要把自己的号再登进号池，那会显示「这就是你的个人账号」，组队照样用它。`配置弹窗 →「负责人组队自动批准」` 默认开，关掉后招人计划要你在侧栏点「待批准」。
- **群聊（自己挑成员同场讨论）**：首页「新建 AI 群聊」；每个成员可选不同的 CLI 和模型；@ 谁只发给谁。适合想对比不同 AI 的看法、或要自己指定成员的场景；只是想把一件事分给几个 AI 做完，用上面的负责人组队更省事。

### 3.3 助理、会议、考勤、PPT（多为可选功能）

- **助理**（可选功能）：整理 WeLink 每日简报、提醒等你回复的消息、回答工作问题。依赖 welink-cli：助理页会提示一键安装，不需要自己装 Node 或管理员权限；本机装了 UniAssistant 时也能认出它自带的 welink-cli。登录方式是助理页左栏的 WeLink 一行「扫码登录」，之后自动续期。不用助理就不需要 welink-cli。
- **会议**：左侧「会议」采集、回放和会议理解，离线转写并生成纪要。
- **会议室**：左侧「会议室」设置自动抢订计划，按园区识别开放时刻，断网后会补抢。
- **考勤**（可选功能）：左侧「考勤」读自己的打卡记录，统计加班和 80 小时红线。页面右上「设置」里可以改：公司域名（考勤地址由它拼出，默认自动找到）、核心工作时间、是否每天自动读取，以及「考勤页」——默认「自动（先正式员工页，再 OD 页）」，也可以指定只用某一页（OD 同事可直接选 OD 考勤页）。
- **PPT**：左侧「PPT」联动 PPT Doctor 找页、做页（选骨架写一句话生成可编辑页）、素材库一键插入；「素材」页可一键下载团队素材包。PPT Doctor 太旧时在组件中心升级。

### 3.4 安装与升级

- **怎么升级**：Hub 启动约 20 秒后自动查新版，之后每 6 小时查一次；只改版本号末位的小版本不弹窗，需要手动点 `设置菜单 →「⬆️ 检查更新」`。一般只下载变化的部分；升级时有进度小窗，**升级途中不要再点图标重开**。改动内容见 `设置菜单 →「📝 更新日志」`，想回到旧版本用「🕘 版本与回退」。
- **自动升级失败**：先在托盘右键退出 Hub（关掉所有 Hub 窗口），再点检查更新；还不行就下载最新「完整安装包」覆盖安装，数据不会丢。
- **安装版还是免安装版**：两种都行；双击安装包没反应时改用免安装 zip，解压到任意文件夹后双击 `AI Hub Community.exe`。公司电脑优先从公司内源 openx 的 AI Hub 项目下载名字带「完整安装包」的条目（Setup 开头的是安装版，win-x64.zip 是免安装版；只写版本号的条目是自动更新包，不用手动下）。
- **窗口全黑**：显卡兼容问题，用兼容渲染方式重装（安装脚本加 `-DisableGpu`）；想恢复显卡渲染，删掉 `%USERPROFILE%\.ai-hub-community\gpu-disabled.json`。
- **公司网络拦了下载或反馈**：底栏「一键放行」，或在弹出的确认页点「放行」后自动继续。

适用：公司内、黄区；截至 11-17

适用：5.6.23 起一键更新一般只下差分包

## 6. 遇到问题怎么一键反馈

1. `设置菜单 →「💬 一键反馈」`，写一句遇到了什么，联系方式可不填。
2. 弹窗里会列出一起附带的内容：版本、系统环境和最近的日志尾部，已自动隐去密钥、口令、Cookie、邮箱和用户目录；不读会话正文和账号凭据。只能发文字，报错原文可以直接贴进描述。
3. 点「发送」，成功后显示反馈编号；把编号发到用户群，维护人能直接对上日志。发送失败时，同样的内容会存到本机「下载」文件夹，可以手动转给维护人。
4. 报错卡片上通常有「一键反馈」按钮，会预填现象和原始报错，比从菜单进更省事。「问问 Hub」答不了的问题，面板里也有「没解决？一键反馈」按钮，会带上你刚才的问题。

## 7. 「问问 Hub」能答什么、不能答什么

- 能答：某个功能、设置在哪；某个报错一般是什么原因、先怎么处理；某个问题在哪个版本修了。
- 不能答：你本机的具体日志和会话内容（它只看这份说明书，不读你的文件、不执行命令）；功能做不做、什么时候做；账号权限开通、信息安全与合规问题。这些请点「一键反馈」或到用户群问维护人。
- 说明书里查不到的，它会直接说「说明书里没有」，并建议一键反馈，不会编一个答案。
