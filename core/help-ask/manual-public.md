## 1. 入门：五分钟上手

1. **前提**：公司电脑上装好 CodeAgent 并已登录（命令行 `codeagent --version` 能显示版本）。没装也能先打开 Hub：首页「连接你的 AI」会显示每个 AI 的安装状态，并给出一键安装、一键登录按钮。
2. **第一次打开**：首页「连接你的 AI」里有「新同事三步上手」——① 检测已装工具（没装就地给「安装」）② 选一个能用的模型（CodeAgent 没登录给「一键登录」，只有部门 key 给「用部门 API key」）③ 发第一句话（点「开始第一个会话」，输入框里已填好一句，按回车即可）；三步做完自动收起，不需要可点「不再显示」。已经用过 Hub 的老用户不会看到它，首页顶部仍是「第一次使用：可以先体检一下」，点「点此体检」检查要用的工具装好没有；也可以随时从 `设置菜单 →「🩺 功能体检与组件中心」` 进入，一键安装 Claude Code、Codex、DSH、PPT Doctor 等组件。
3. **新建会话**：左上角蓝色「＋ 启动」直接用上次的配置开一个会话；点旁边的小箭头（或按 Ctrl+N）打开「启动中心」，选 AI（CodeAgent / Claude Code / Codex / DSH / pi / PowerShell）、模型和工作文件夹。工作文件夹就是 AI 查看材料、写文件的地方，启动中心会记住上次用的文件夹。
4. **聊天**：会话里默认是「卡片」视图，下方输入框回车发送、Shift+回车换行（可在 `配置弹窗 →「回车键」` 改成回车换行、Ctrl+回车发送）。输入框下方的模型名点一下就能换模型，对话记录保留。
5. **看原始终端**：会话顶栏的「后台」按钮切到 CLI 原始终端；它右边的小箭头是「后台显示方式」，可选卡片和终端单独显示或左右并排。
6. **多个 AI 一起干活（推荐负责人组队）**：新开一个 CodeAgent 会话，把任务说清楚，加一句「需要的话组队做」，它会自己当负责人、按需招队友分工、审查后向你汇报，你只跟它说话。只有一个账号也能组队（队友共用你的账号）。想自己挑几个不同的 AI 同场讨论、对比看法，再用首页「新建 AI 群聊」，在群聊输入框里 @ 谁就只发给谁。
7. **可选功能默认关**：助理、帖子、考勤、门户待办、关窗口时最小化到托盘、桌宠这些功能默认关闭，在 `设置菜单 →「🧩 可选功能」` 里自己打开；v5.6.77 起第一次关窗也会询问退出还是最小化到托盘，按你选择记住。左侧导航上找不到某个页面时，先去这里看看。
   **低开销模式**（风扇响、内存紧时用）：`配置弹窗 →「资源与后台」` 页顶上的总开关。打开后助理、帖子、考勤、门户待办、会议室、桌宠、底栏网速与显卡读数、后台会话搜索索引、CodeAgent 多账号额度自动刷新全部关掉，只留会话；哪项用到了，在它自己的页面上点「开启」即可。同一页每行显示这项当前占了多少内存、几个进程、多少 CPU。新装默认打开；老用户升级不改任何开关，只在右下角提示一次。
8. **数据在哪**：用户数据在 `%USERPROFILE%\.ai-hub-community`，覆盖安装、升级、换版本都不会动它。

### 2.6 可选功能清单（设置菜单 →「🧩 可选功能」）

- **助理**：整理每日简报、提醒待处理的 WeLink 消息，并回答工作问题。会议和会议室可以单独使用。开销：开着时工作日每 10 分钟后台读一次 WeLink，每分钟检查一次登录
- **帖子**：公司发文（政策讲话、公司文件、公告）和心声、稼先今天的热帖，附 AI 摘要；发文上新会提醒。开销：开着时工作日早上在后台用无头 Edge（借本机 Edge 的登录状态，不弹窗）取一次，之后每小时只重看发文；没登录会每 30 分钟重试
- **考勤**：读自己的打卡记录，统计加班、80 小时红线和年度工时。开销：开着时每天在后台打开一次考勤页（隐藏窗口，取不到时用无头 Edge），当天取到就不再访问
- **门户待办**：读公司门户首页上自己的待办、提的申请和公司文件；新待办、拖了很久的待办和卡住的申请会提醒。开销：开着时每天早上 6 点后在后台用无头 Edge 打开一次门户首页（约 10 秒、不弹窗），当天取到就不再访问；页面上可随时手动刷新
- **会议室**：按你的规则每天放号时自动抢订会议室，结果和快开会了由桌宠或通知卡提醒。开销：开着时每 15 秒看一次抢订结果；打开过会议室页后，后台常驻一个会议室组件进程（约几十到一百多 MB 内存）
- **关窗口时最小化到托盘**：点窗口右上角的关闭只把 Hub 收到右下角托盘，会话照常在后台跑；单击托盘图标打开，右键「退出 AI Hub」才真正退出。开销：几乎没有，只多一个托盘图标
- **再打开 Hub 时提示切过去**：已经开着一个 AI Hub 时再双击图标，先问一句「已在运行，切过去？」；选「再开一个」照样能开两个。开销：没有，只在打开 Hub 时看一眼
- **桌宠**：桌面角落的小猫：会话答完、提醒、会议室结果都由它举卡片告诉你，右键还能问助理。开销：开着时一直有一个置顶的小窗口，每 0.1 秒看一次光标是否碰到它
- **底栏网速与显卡读数**：左下角的 ↓↑ 实时网速和 GPU 占用；CPU、内存读数不受影响。开销：开着时常驻一个 PowerShell 读网卡（约 150 MB 内存），每 10 秒运行一次 nvidia-smi 读显卡
- **后台会话搜索索引**：启动后趁电脑空闲给历史会话建搜索索引，之后跟着新会话自动更新，搜索时立刻出结果。开销：第一次要扫描全部会话记录（记录多时要几分钟，磁盘和 CPU 都会忙），之后常驻一个搜索进程并监听会话目录。关着时搜索照样能用，第一次搜时当场建索引
- **CodeAgent 多账号额度自动刷新**：有两个以上 CodeAgent 账号时，每 15 分钟把各号的剩余额度读一遍。开销：每读一个号临时起一个 CodeAgent 后台进程（约 0.5 GB 内存），读完即关。关着时额度面板里手动刷新照样能用

## 3. 常用操作怎么做

### 3.1 模型与账号

- **换模型**：会话输入框下方点模型名，选另一个即可，对话不丢。新建会话的默认模型在启动中心里选。
- **模型列表里少了模型 / 选不到**：模型列表读的是本机 CodeAgent 账号的权限，各人不同。先 `设置菜单 →「⬆️ 检查更新」` 升到最新版（旧版曾把名字带括号的模型过滤掉），再到左侧「账号」页确认 CodeAgent 已登录、额度正常；仍然少，就点「💬 一键反馈」。
- **报「模型不存在或配置有误」/ 400 Invalid model name**：这个账号没有该模型的权限或模型改了名（换号、号过期后常见）。点输入框下方的模型换一个；选过一次替代后，新会话会直接用替代模型。
- **CodeAgent 账号、号池额度**：左侧「账号」页管理登录状态和号池；底栏和右侧栏显示剩余额度。
- **用部门 API key / 自己的接口**：三个入口任选——① 首页「连接你的 AI」里的「用 API key 开始」，粘贴 key 即可（网关地址已预填，key 用 Windows 账户加密保存）；② 启动中心的模型卡里点「用部门 API key」，就地粘贴；③ `设置菜单 →「⚙️ 设置」→ 顶部「自有 API」→「配置接口」`，Claude Code、Codex、DSH 每个工具可分别选「公司模型」「API 网关」或「自己的接口」。Hub 还会自动检测你在 Claude Code、Codex、VS Code 等工具里配过的网关 key，一键使用。
- **让 Claude Code、Codex、DSH 也用公司模型**：同上 ③ 里选「公司模型」，走 CodeAgent 登录的公司线路，所以 CodeAgent 必须先登录有效。报「首次签名初始化没完成」时：确认 CodeAgent 命令行能正常对话，再在「自有 API」里点「重新启动模型通道」。
- **Key 存在哪**：API 网关 key 用 Windows 账户加密，存在数据目录的 `api-gateway/gateway.json`；「自有接口」Key 同样用 Electron safeStorage（Windows 下为 DPAPI，绑定当前 Windows 账户）加密，保存在 `config.json`、`config.json.bak` 和 `cli-api-profiles/<工具>/<账号>/<修订>/connection.json`。旧配置和备份在加密与保存成功后清除明文字段；旧连接快照按读取迁移，未读取的历史快照保留原状。
- **共享切换与旧会话**：切换到内网共享池前的接口备份位于 `lan-pool/settings.json`，其中的自有接口 Key 同样加密，断开共享时恢复。旧明文快照迁移写回失败时保留原文件，继续恢复原会话，下次读取再迁移；新建快照必须加密保存成功，否则停止启动并提示。
- **CLI 的明文例外**：`connection.json` 由 Hub 读取，不需要明文交给 CLI。Codex CLI 必须读取的 `auth.json` 仍存明文 Key，位于 `cli-api-profiles/codex` 下的账号目录或 `codex-api-profile` 目录；Claude Code、DSH 通过启动进程的环境变量接收 Key。不要分享整个数据目录；反馈只提供脱敏报错，Key 留在本机配置窗口。详见随包 `PRIVACY.md`。
- **Key 无法解密**：换机、换 Windows 账户或密文损坏导致解不开时，在启动中心点击对应账号的「点此补填」，或打开它的自有接口设置，补填 Key 后点「保存并继续」。

#### 没有 CodeAgent 账号，接部门自有模型（部门自有平台、部门 GLM 等）

两个选项的区别（弹窗里每个选项下也写了这一句）：
- **API 网关**：部门统一发的 key，走公司 API 网关，按部门计费，模型由网关提供。
- **自有接口**：自己填 URL、模型名和 key，任何兼容 OpenAI 或 Anthropic 的接口都可以（Claude Code 只认 Anthropic 格式，填 OpenAI 兼容地址见下面第 3 条）。

先分清手里是哪一种，再按对应的一条做（都在 `设置菜单 →「⚙️ 设置」→ 顶部「自有 API」→「配置接口」`，上方切换 Claude Code / Codex / DSH）：

1. **部门发的 API 网关 key（通常以 sk- 开头，地址是部门统一网关）**：选「API 网关」，粘贴 key →「保存配置」。保存时 Hub 先请求一次模型列表验证（不发对话、不耗额度），通过后 Claude Code、Codex、DSH 都能勾选同时使用。Claude Code 用这条最稳：Hub 在本机把 Claude 的请求转成 OpenAI 格式。
2. **自己的 OpenAI 兼容地址（平台给了「接口地址 + Key + 模型名」）**：选「自有接口」，填接口地址（一般以 /v1 结尾，漏了 Hub 会自动补）、Key，点「测试连接」——通过后在「接口上的模型」下拉里选模型，再「保存配置」。DSH 必须填模型名；保存后新建 DSH 会话，启动中心默认选中「自有接口」卡。
3. **Claude Code 填了 OpenAI 兼容地址**：Claude Code 只认 Anthropic 格式，直接填会报 404 或格式错误。「测试连接」通过后弹窗里会出现「改用 API 网关接入」，再粘贴一次 key 点它即可，地址、Key、模型照用。
4. **同一个工具有多个平台账号**（Claude Code、Codex）：「API 账号」下拉里「＋ 添加 API 账号」可存多组；选中某个账号能直接改名称、地址、模型（Key 留空保留原 Key），点「删除此账号」再点「确认删除」可删掉。已开的会话不受影响。

常见报错与下一步：

| 看到的提示 | 原因 | 下一步 |
|---|---|---|
| key 无效 / 401 | Key 复制不完整或已失效 | 重新复制完整 Key 粘贴，「测试连接」 |
| 连不上接口：10 秒内没有响应 | 电脑不在能访问该平台的网络里（在家没连 VPN、黄区平台在绿区访问等），或地址写错 | 换到能访问的网络；核对地址 |
| 接口上没有这个模型 | 模型名拼错，或平台换了新模型 | 「测试连接」后在「接口上的模型」里重新选 |
| DSH 还没选模型来源 / 还没填模型名 | DSH 没配任何一种来源，或自有接口缺模型名 | 按上面 1 或 2 配好再新建 DSH 会话 |
| DSH 显示「未安装」 | 这台电脑还没有 DSH 终端运行环境 | 启动中心点 DSH 卡片「一键安装」 |
| DSH 会话一直「启动中」，或报「DSH 启动失败——插件 tools …」 | 装的 DSH 比这版 Hub 新，插件配置不配套（11-20 前的 Hub 遇到 npm 最新版 DSH 必现） | 先升级 Hub 到最新版；仍不行点「一键修复 DSH」或「一键反馈」 |

### 3.2 会话、群聊、组队

- **恢复以前的会话**：启动中心里切到「恢复会话」，可以接任意目录的 CodeAgent 历史；侧栏「搜索历史」（Ctrl+Shift+F）全局搜以前的对话。
- **重命名、分组、置顶**：右键会话「重命名会话」；会话整行可拖进侧栏目录分组；侧栏顶部「置顶 / 今天 / 3 天」切换范围。
- **会话卡住、提示「CLI 已退出，请先重启会话」**：点提示里的重启会话；报错卡片上的「问问 Agent」会开一个排查会话，几分钟内给出排查结论。
- **省内存**：闲置会话自动休眠，内存超过 85% 时先休眠早已答完的会话；点一下会话就唤醒，记录都在。`设置菜单 →「💤 自动休眠」` 可立即扫描一次。
- **负责人组队（多 AI 分工干活的推荐用法）**：不用找入口，也不用先建群——新开一个 CodeAgent 会话，说清任务并加一句「需要的话组队做」，这个会话就是负责人：它判断要不要队友、自己招人、分工、审查，最后向你汇报，你只跟它说话。队友由负责人按任务现招，不用你预先建，也不用每次重选；招来的队友显示在侧栏负责人那一行下面，点开就是普通会话。号池里有可用账号时队友优先用号池；号池没号、或者只有你自己一个号时，队友自动用你的个人账号（和负责人共用额度，个人账号上同时最多 3 个队友在干活，多出的排队）；不要把自己的号再登进号池，那会显示「这就是你的个人账号」，组队照样用它。`配置弹窗 →「负责人组队自动批准」` 默认开，关掉后招人计划要你在侧栏点「待批准」。
- **群聊（自己挑成员同场讨论）**：首页「新建 AI 群聊」；每个成员可选不同的 CLI 和模型；@ 谁只发给谁。适合想对比不同 AI 的看法、或要自己指定成员的场景；只是想把一件事分给几个 AI 做完，用上面的负责人组队更省事。

### 3.3 助理、会议、考勤、PPT（多为可选功能）

- **助理**（可选功能）：整理 WeLink 每日简报、提醒等你回复的消息、回答工作问题。依赖 welink-cli：助理页会提示一键安装，不需要自己装 Node 或管理员权限；本机装了 UniAssistant 时也能认出它自带的 welink-cli。登录方式是助理页左栏的 WeLink 一行「扫码登录」，之后自动续期。不用助理就不需要 welink-cli。
- **Hub 怎样读到 WeLink 消息**：靠 welink-cli（WeLink 官方命令行工具），Hub 本身不直接连 WeLink。它有自己的一份登录（扫码得到，存在本机 `%USERPROFILE%\.welink-cli\credentials.json`），每次查消息、会议、邮件或一键反馈发消息时，还要向这台电脑上开着的 WeLink 桌面端取一份签名，所以桌面端要开着并登录本人账号。
  - **怎么登录**：助理页左栏 WeLink 一行点「扫码登录」，用手机 WeLink 扫码并确认；之后 Hub 自动续期，不用再管。
  - **换了工号以后**：WeLink 桌面端登的是新工号，welink-cli 还留着旧工号的登录，两边对不上，WeLink 会拒收请求，助理和一键反馈都会报「proxy failed」。Hub 会以桌面端当前登录的账号为准，发现对不上时在助理页 WeLink 一行和一键反馈窗口里写明「WeLink 命令行还登着旧账号 X」，点旁边的「重新登录」：Hub 先清掉旧账号的登录，再出二维码，用新工号的手机 WeLink 扫一下即可。Hub 存过的旧身份（个人页的名字、工号）也会自动作废、按新账号重认。
  - **一键反馈发不出去时**：窗口里会写明原因，旁边就有「复制内容」「复制并打开 WeLink」，复制后在 WeLink 里搜维护人账号粘贴发送即可。
- **会议**：左侧「会议」采集、回放和会议理解，离线转写并生成纪要。
- **会议室**：左侧「会议室」设置自动抢订计划，按园区识别开放时刻，断网后会补抢。
- **考勤**（可选功能）：左侧「考勤」读自己的打卡记录，统计加班和 80 小时红线。页面右上「设置」里可以改：公司域名（考勤地址由它拼出，默认自动找到）、核心工作时间、是否每天自动读取，以及「考勤页」——默认「自动（先正式员工页，再 OD 页）」，也可以指定只用某一页（OD 同事可直接选 OD 考勤页）。
- **PPT**：左侧「PPT」联动 PPT Doctor 找页、做页（选骨架写一句话生成可编辑页）、素材库一键插入；「素材」页可一键下载团队素材包。PPT Doctor 太旧时在组件中心升级。

### 3.4 安装与升级

- **怎么升级**：Hub 启动约 20 秒后自动查新版，之后每 6 小时查一次；只改版本号末位的小版本通常不弹窗，允许自动更新且安装目录可写时会在后台下载，下次关闭 Hub 时替换、再打开生效。可随时点 `设置菜单 →「⬆️ 检查更新」` 查看状态或手动更新；关闭自动更新、固定旧版或需要管理员授权时按界面提示处理。一般只下载变化的部分；**升级途中不要再点图标重开**。改动内容见 `设置菜单 →「📝 更新日志」`，想回到旧版本用「🕘 版本与回退」（旧版本只从公司内源取，需连着公司网络）。
- **自动升级失败**：先在托盘右键退出 Hub（关掉所有 Hub 窗口），再点检查更新；还不行就下载最新「完整安装包」覆盖安装，数据不会丢。
- **安装版还是免安装版**：两种都行；双击安装包没反应时改用免安装 zip，解压到任意文件夹后双击 `AI Hub Community.exe`。公司电脑优先从公司内源 openx 的 AI Hub 项目下载名字带「完整安装包」的条目（Setup 开头的是安装版，win-x64.zip 是免安装版；只写版本号的条目是自动更新包，不用手动下）。
- **窗口全黑**：显卡兼容问题，用兼容渲染方式重装（安装脚本加 `-DisableGpu`）；想恢复显卡渲染，删掉 `%USERPROFILE%\.ai-hub-community\gpu-disabled.json`。
- **公司网络拦了下载或反馈**：更新和组件只从公司内源下载，确认电脑连着公司内网或 VPN 后重试。

### 3.5 Hub 配置、工作目录与日志

- **Hub 配置存在哪**：Windows 默认数据目录是 `%USERPROFILE%\.ai-hub-community`（资源管理器地址栏粘贴即可打开），主配置文件是其中的 `config.json`。如果启动时指定了 `CLAUDE_HUB_DATA_DIR`，以该变量指向的实际数据目录为准。这是 AI Hub 自身的配置，不是 CodeAgent 的 `.cac` 配置；程序安装目录也不是数据目录。
- **想清空配置重新试**：先从托盘退出 Hub，确认所有 Hub 窗口已关闭；把实际数据目录完整复制到另一个备份目录。只重置 Hub 设置时，把原目录里的 `config.json` 改名为 `config.json.before-reset`（已有同名备份就另起名字），再启动 Hub，缺失的设置会回到默认值；`config.json.bak` 是旧配置备份，不要用它覆盖刚重置的配置。会话记录、账号和其他独立配置不会因此全部重置。需要回退时退出 Hub，再把备份文件恢复为 `config.json`。不要删除整个数据目录或 CodeAgent 的配置目录。
- **想以全新 Hub 状态启动**：完整备份并退出 Hub 后，把实际数据目录改名保留，再启动；Hub 会创建新数据目录，原会话和 Hub 内保存的账号设置暂时看不到，CLI 自身的登录与配置仍在。恢复旧数据时先退出，把新目录也改名保留，再把旧目录恢复原名。没有一键重置按钮时按此操作，不要编造菜单入口。
- **工作目录不想放 C 盘**：v5.6.79 起，在 `设置菜单 →「⚙️ 设置」→「外观与输入」→「新建会话默认工作目录」` 点「选择…」选 D 盘目录并保存；下一个新建会话选择「默认工作目录」时生效，已有会话继续使用原目录。启动时设置了 `AI_HUB_WORKSPACE_ROOT` 时该环境变量优先。
- **PPT 仍在 C 盘处理**：新建会话目录与 Hub 工作文件目录是两项设置。到 `设置菜单 →「⚙️ 设置」→「高级」→「Hub 工作文件根目录」` 选 D 盘目录，保存后重启 Hub，新建的 PPT 工作区放到该目录下的 `ppt-workspace`；已有文件留在原处，不会自动搬走。配置、凭据、缓存和安装工具仍留在数据目录；不要为搬 PPT 直接删除数据目录。
- **日志在哪**：实际数据目录下的 `logs` 文件夹保存 Hub 诊断日志；「问问 Hub」的本机问答运行记录在 `help-ask\history.jsonl`，不包含回答原文。反馈优先用 `设置菜单 →「💬 一键反馈」`，它会附带脱敏后的环境和日志尾部，不要直接分享整个数据目录。
- **输入框太小**：普通会话和 CodeAgent 会话可拖动输入栏上边沿调整高度，下次打开会记住；点发送按钮旁的「展开大输入框」可编辑长消息。「应用」只回填草稿，「发送」才提交，取消或 Esc 保留原草稿。

## 4. 常见问题（用户群标准答复）

> 每条注明适用范围；仓库内已核对的新版答复会整条替换旧卡，旧答案不进入本节。带历史日期的未替换答复仅适用于所注明时期；请先按本机版本和第 3 节操作，不把旧版故障或限制当成现版行为。第 5 节中旧版本更新记录只用于查变更经过。

**Q：公司内/黄区能不能用**
也有人这么问：「AI hub 公司内可以用吗」 「黄区能使用吗」 「codex可以用么，黄区。」
答：可以用。前提是本机装了 CodeAgent 并且已经登录，黄区也一样。Claude Code、Codex 会话走公司模型反代，用的也是 CodeAgent 这条公司线路。CodeAgent 的账号、权限或者它自己出了问题，要找本部门负责人。另外提醒一句：黄区连远程执行机的会话目前还不支持。
适用：公司内、黄区；截至 11-17
不适用/另行处理：问黄区远程执行机会话什么时候支持：已记录，转维护人

**Q：下载地址（内源）**
也有人这么问：「工具有下载链接吗」 「求内源地址」 「公司电脑去哪里下AI HUB」
答：公司电脑去内源下完整安装包，一键下载：公司内源 openx 上的 AI Hub 项目页 ；内源地址：公司内源 openx 上的 AI Hub 项目页 。装好后在 AI HUB 里自己更新就行。
适用：11-24 维护人在 1 群、2 群发的地址

**Q：下载/更新慢、选哪个源**
也有人这么问：「升级的有点慢，大家是不是都这样」 「这是啥 怎么还有阿里云啥的」 「阿里云高速有些低速」
答：公司电脑最快的办法是直接去内源下「完整安装包」覆盖安装，数据不会丢。外网的几个源里，实测 GitHub 最快，阿里云的「高速」不一定快。平时一键更新一般只下变化的部分（约 0.3 MB）。自动更新全程走内网的建议，维护人 11-16 已经收到，现在做到哪一步以更新日志为准。
适用：5.6.23 起一键更新一般只下差分包
不适用/另行处理：5.6.103 起下载和更新只走公司内源，界面不再有阿里云和 GitHub 选项

**Q：下载时弹风险提示**
也有人这么问：「这风险能接受吗」 「下载的时候弹出风险确认，要点接受吗」
答：这是从阿里云下载时公司网络弹出的确认。换 GitHub 下载就不会弹，不用点接受；公司电脑更推荐直接去内源下载。
适用：从阿里云下载时弹出风险确认
不适用/另行处理：5.6.103 起下载和更新只走公司内源，不再从阿里云下载

**Q：黄区/公司电脑网络配置与放行**
也有人这么问：「黄区需要配网络吗」 「下载弹确认访问页怎么办」
答：先使用公司允许的网络。Hub 的更新和组件只从公司内源下载，连不上时确认电脑连着公司内网或 VPN 后重试；弹出公司网络确认页时按页面提示操作后重试。
适用：v5.6.62 起统一安装包；具体代理放行效果仍需黄区真机确认

**Q：安装后打不开/安装闪退**
也有人这么问：「AI-HUB安装后打不开，请问怎么解决」 「免安装版也打不开」 「双击安装包没反应」
答：先用 v5.6.45 及以后的安装包，这一版修好了公司电脑上安装包闪退的问题。还打不开，多半是电脑权限或安全软件拦截。可以改用内源的免安装 zip，解压到自己的用户目录，双击 AI Hub Community.exe，不需要管理员权限；也可以把安装包丢给 CodeAgent，让它帮你安装、打开。CodeAgent 要是查到了具体原因，请一键反馈告诉维护方，下个版本加上保护。
适用：v5.6.45 起安装包闪退已修（11-17 发布）
不适用/另行处理：窗口能打开但全黑：见「窗口全黑」那一条；数据丢失、装完电脑异常这类事故：转维护人

**Q：窗口全黑**
也有人这么问：「打开后窗口全黑」 「界面黑屏什么都不显示」 「软件打开蓝屏，不显示界面」
答：这种情况用兼容渲染（-DisableGpu）方式重新安装。以后想恢复显卡渲染，删掉 %USERPROFILE%\.ai-hub-community\gpu-disabled.json 就行。如果是根本打不开、不是黑屏，按「安装后打不开/安装闪退」那一条 处理。
适用：窗口能打开，但显示全黑
不适用/另行处理：双击完全没反应、启动就退出：按「安装后打不开/安装闪退」那一条 处理

**Q：点「立即安装」没反应**
也有人这么问：「更新了之后点立即安装没反应啊」 「是不是因为我在内源下的，直接解压缩运行，它检索不到安装位置？」 「没反应+1」
答：多半不是免安装版的问题，而是打开安装包时被电脑里的安全卫士拦了，有些同事遇到过。让 CodeAgent 帮你打开安装包就行。还不行就在托盘右键退出 Hub，去内源下最新的「完整安装包」覆盖安装，数据不会丢；免安装版直接解压到一个新文件夹就行。
适用：11-16 起的答法；v5.6.45 起安装包闪退已修

**Q：启动弹 HIS 弹窗**
也有人这么问：「打开软件就是HIS的弹窗，可以填继续吗」 「启动弹出HIS提示怎么办」
答：这个弹窗直接关掉也没事。
适用：打开 AI HUB 时弹出 HIS 弹窗
不适用/另行处理：关掉后某个功能用不了：把弹窗文字和现象写进一键反馈

答：API 网关 key 用 Windows 账户加密，存在 Hub 数据目录的 api-gateway/gateway.json。「自有接口」Key 同样用 Electron safeStorage（Windows 下为 DPAPI，绑定当前 Windows 账户）加密，保存在 config.json、config.json.bak，以及 cli-api-profiles/<工具>/<账号>/<修订>/connection.json 连接快照中。切换到内网共享池前的接口备份位于 lan-pool/settings.json，其中的自有接口 Key 同样加密，断开共享时恢复。旧配置和备份在加密与保存成功后清除明文字段；旧快照按读取迁移，未读取的历史快照保留原状。旧明文快照迁移写回失败时保留原文件，继续恢复原会话，下次读取再迁移；新建快照必须加密保存成功，否则停止启动并提示。连接快照由 Hub 读取，不需要明文交给 CLI。Codex CLI 必须读取的 auth.json 仍存明文 Key，位于 cli-api-profiles/codex 下的账号目录或 codex-api-profile 目录；Claude Code、DSH 通过启动进程的环境变量接收 Key。换机、换 Windows 账户或密文损坏导致解不开时，打开对应账号补 Key，点「保存并继续」。Hub 数据目录不要公开分享或提交到 Git。发起模型请求时仍需把必要凭据交给你配置的服务。
适用：网关从 v5.6.57 起加密；自有接口按本次 safeStorage 加密实现核对，旧快照按需迁移，Codex 原生 auth.json 仍明文

## 6. 遇到问题怎么一键反馈

1. `设置菜单 →「💬 一键反馈」`，写一句遇到了什么，联系方式可不填。
2. 弹窗里会列出一起附带的内容：版本、系统环境和最近的日志尾部，已自动隐去密钥、口令、Cookie、邮箱和用户目录；不读会话正文和账号凭据。只能发文字，报错原文可以直接贴进描述。
3. 公司网络下优先显示「一键发到 WeLink」；本机没装 welink-cli 时显示「复制并打开 WeLink」，按窗口提示粘贴给维护人。完整诊断包存在本机「下载」文件夹；WeLink 没打开或没登录时先打开并登录再重试。其他网络使用窗口中的「发送」，成功时按提示保留反馈编号；失败时可从「下载」取诊断文字手动反馈。
4. 报错卡片上通常有「一键反馈」按钮，会预填现象和原始报错，比从菜单进更省事。「问问 Hub」答不了的问题，面板里也有「没解决？一键反馈」按钮，会带上你刚才的问题。

## 7. 「问问 Hub」能答什么、不能答什么

- 能答：某个功能、设置在哪；某个报错一般是什么原因、先怎么处理；某个问题在哪个版本修了。
- 不能答：你本机的具体日志和会话内容（它只看这份说明书，不读你的文件、不执行命令）；功能做不做、什么时候做；账号权限开通、信息安全与合规问题。这些请点「一键反馈」或到用户群问维护人。
- 说明书里查不到的，它会直接说「说明书里没有」，并建议一键反馈，不会编一个答案。
